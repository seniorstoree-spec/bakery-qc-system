# نظام إدارة ومراقبة وتأكيد الجودة - قسم المخبوزات | شركة العبد
## Quality Control & Assurance Daily Management System

نظام ويب تفاعلي متجاوب مصمم بالكامل باللغة العربية بواجهة RTL للرقابة اليومية على جودة قسم المخبوزات (مخبوزات 1 ومخبوزات 2) في شركة العبد للإستثمار والتصنيع وتجارة الحلوى، استناداً إلى تقارير الجودة القياسية ومواصفات الأيزو وسلامة الغذاء HACCP / ISO 22000.

---

### التحديثات
- إصلاح تحميل بيانات التقارير المؤرشفة بشكل مستقل لكل قسم.
- إعادة بناء Snapshot للتقرير عند فتح تقرير قديم بدون بيانات محفوظة.
- الحفاظ على بيانات الأقسام الموجودة وعدم إسقاط التقرير بالكامل بسبب خطأ في جدول فرعي.
- إظهار بيانات إذن الإفراج حتى مع القرار قيد الانتظار.
- عرض أقسام التقرير المؤرشفة التي تحتوي على بيانات فعلية.
- إصلاح تشغيل Vercel بعد تعديلات نماذج النظافة والتطهير وGHP.

### التشغيل
```bash
npm install
npm run dev
npm run build
```
